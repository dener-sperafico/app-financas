Política de privacidade

Oikon · finanças da casa · atualizada em 23/11/2026

O que o Oikon é

O Oikon é um app pessoal para organizar o dinheiro da casa. Ele roda no seu navegador e guarda tudo numa planilha do Google que fica no seu próprio Google Drive.

Quais dados o app acessa

  • Só os arquivos que o próprio Oikon criou no seu Drive (permissão drive.file). O app não vê nem lê seus outros arquivos.
  • O que você lança no app: saldos, lançamentos, cartões, categorias e orçamentos. Tudo isso vai para a sua planilha.

Onde os dados ficam

Na sua planilha, no seu Google Drive. O Oikon não tem banco de dados próprio e não envia seus dados financeiros para nenhum servidor nosso. Uma cópia temporária pode ficar no armazenamento do navegador para o app funcionar offline.

Para manter você conectado sem pedir login toda hora, o app pode guardar uma autorização de acesso do Google (token) num serviço próprio. Esse token só permite acessar os arquivos criados pelo Oikon e pode ser revogado a qualquer momento.

Com quem compartilhamos

Com ninguém. Não vendemos, não usamos para publicidade e não compartilhamos seus dados. O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

Você pode revogar o acesso do Oikon a qualquer momento em myaccount.google.com/permissions. A planilha continua sua: para apagar os dados, é só excluir o arquivo do seu Drive.
